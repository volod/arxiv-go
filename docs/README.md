# Documentation

This directory separates product intent, forward work, current behavior and contributor guidance.

## Start here

- [Product specification](openspec/spec.md) defines purpose, scope, capabilities, stages and
  evaluation; stage pages hold detailed behavior.
- [Architecture](openspec/architecture.md) maps behavior onto packages and transactions.
- [Forward implementation plan](impl/plan.md) contains only work that remains.
- [Current implementation](impl/current.md) indexes behavior available in the repository.
- [Planning workflow](guide/planning-workflow.md) explains task lanes and the record lifecycle.
- [Development guide](guide/development.md) lists toolchain, Make targets and conventions.
- [Project rules](../AGENTS.md) govern agent and contributor behavior.

## Document ownership

| Question | Source of truth |
| --- | --- |
| What should the utility do? | [Specification tree](openspec/README.md) |
| What work remains? | [Implementation plan](impl/plan.md) |
| What exists and where? | [Current implementation](impl/current.md) |
| What was decided and proven? | [Task records](impl/records/README.md) |
| How should work be performed? | [Contributor guide](guide/README.md) and [AGENTS.md](../AGENTS.md) |
